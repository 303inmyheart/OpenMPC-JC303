# Drive model credits and display names

Neutral display names keep third-party manufacturer names out of the skin and
screenshots, as required by the OpenMPC catalog's branding policy. Original
names are credited here; no endorsement is implied. Order and original filenames
are retained, so stored model identities and existing sounds are unchanged.
